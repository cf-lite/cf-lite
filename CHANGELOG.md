# Changelog

Derived from git history (`git log`); the project is pre-1.0 (0.x). Of the seven packages in `docs/published.md`, the registry has all seven at 0.4.2 (checked 2026-10-06). Entries under Unreleased describe `main`.
Versions below are the `version` fields of the packages at the commit noted.

## 0.4.2 (2026-10-06)

### Removed

* **`cfl init opti`** (`cf-lite init opti <dir> --cms cda|graph --version 12|13`, present in 0.4.0): it only handed over to a separate starter package that is not published, so it could not work for anyone installing `cf-lite` from npm. The command, its resolver (`src/init-opti.ts`) and its docs are gone; `cf-lite init` itself is unchanged. The generic part of the neighbouring code (`@cf-lite/react/detect`, the static/ssr/island rules) stays, with its wording no longer referring to that starter.
