# Third-party notices

cf-lite itself is MIT licensed ([LICENSE](LICENSE)). This file lists the third-party material that is **committed in this repository** (fonts, wasm helpers) or **bundled into the OG image Worker** (`packages/cf-lite/og-worker`, not published to npm) with the licence texts those licences require. Ordinary npm dependencies are not listed here: they are installed from the registry with their own licence files, and the published packages declare their dependencies in `package.json`.

| Material | Where | Licence |
|---|---|---|
| DejaVu Sans Bold (derived from Bitstream Vera and Arev) | `examples/site-blog/public/fonts/DejaVuSans-Bold.ttf` (an example's OG image font, test fixture) | Bitstream Vera licence with public-domain DejaVu changes, text below |
| Be Vietnam Pro Regular (latin subset, WOFF2) | `packages/cf-lite/test/fixtures/be-vietnam-pro-400-latin.woff2` (font-metrics test and browser e2e fixture, never shipped in a package) | SIL Open Font License 1.1, text below |
| harfbuzzjs 0.10.0 (HarfBuzz compiled to wasm) | bundled by `packages/cf-lite/og-worker` (wrangler `alias` in `src/harfbuzz.ts`), read from `node_modules` at build time, not copied into the repository | MIT, text below (HarfBuzz itself is under the "Old MIT" licence, see https://github.com/harfbuzz/harfbuzz/blob/main/COPYING) |
| satori 0.33.x (HTML and CSS to SVG) | bundled by the OG Worker, from `node_modules` | MPL-2.0, https://www.mozilla.org/MPL/2.0/ ; source: https://github.com/vercel/satori |
| @resvg/resvg-wasm 2.6.x (SVG to PNG) | bundled by the OG Worker, from `node_modules` | MPL-2.0, https://www.mozilla.org/MPL/2.0/ ; source: https://github.com/yisibl/resvg-js and https://github.com/RazrFalcon/resvg |
| `og-worker/src/fn-sigs/*.wasm` | six tiny WebAssembly function-signature trampolines generated by `og-worker/scripts/gen-fn-sigs.mjs` | cf-lite, MIT (no third-party code) |

The MPL-2.0 libraries are used unmodified. A deployed OG Worker contains them in compiled form; their source is available at the links above and in the package versions pinned in `bun.lock`.

The font files are redistributed as part of an example and test fixtures. If you copy them into an application, keep the licence text below with them. Fonts you add to your own app (for example through `fonts()` in `cf-lite/vite`) carry their own licences; cf-lite does not bundle any font into a published package.
